Pre-work

Llega preparado para el hands-on con Data 360.

Preparación propuesta a partir de la guía práctica del programa. Pendiente de validar el alcance del pre-work con el equipo.

  1. Revisa la guía práctica

    Lee el objetivo y el apartado «Antes de empezar» de SOMA Casa: GitHub Pages + Salesforce Data 360.

  2. Comprueba tu cuenta de GitHub

    Necesitarás acceso para crear tu propio repositorio y configurar GitHub Pages.

  3. Confirma el acceso a Data 360

    Comprueba que tu organización tiene Data 360 habilitado y que dispones de permisos para Website Connectors, Data Streams y mapeos.

  4. Prepara el navegador

    Comprueba que puedes acceder a GitHub y Salesforce, y que JavaScript está habilitado.
